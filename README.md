# simple word test
単語テストを実施できます。  
ジャッジは完全一致を要求します。ただし、大文字小文字は区別しません。  
指定したファイルについて処理が終了すると、結果が表示されます。結果は、問題と誤答のみを含みます。
## 使用法
「標準」にあるボタンを押すと、そのデータをインポートします。  
また、後述する記法で記述されたテキストファイルを選択することでも問題を選択できます。  
ファイルを選択した後は、モードが希望のものになっていることを確認し、「始める」を押します。  
その後は、フィールドに入力し、Enterを押下、もしくは「OK」を押すことで送信できます。  
フィードバックとして、正解なら「CA!」,そうでないなら「WA! 正解:<正答>」と表示されます。
## 問題のかきかた
行頭に「#」がある行はコメントとして受理されます。  
ある一つの問題について、「単語」「タブ」「意味」の順に記述します。例えば、以下のようになります。  
```
apple	        りんご
take care of	世話をする
in order to	    〜するために
as to	        〜するために
```
