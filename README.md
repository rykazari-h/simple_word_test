# simple word test
[page](https://simple-word-test.pages.dev)  
単語テストを実施できます。  
ジャッジは完全一致を要求します。ただし、大文字小文字は区別しません。  
指定したファイルについて処理が終了すると、結果が表示されます。結果は、問題と誤答のみを含みます。
## 使用法
スロットの数だけファイルを選択することができます。
ピンクのボタンを押してexamples/のものを取得するか、ローカルのファイルを選択します。
ファイルの選択は最後尾の空スロット、もしくは最後尾スロットに適用されることに注意してください。
ファイルを選択した後は、モードが希望のものになっていることを確認し、「始める」を押します。  
その後は、フィールドに解答を入力し、Enterを押下、もしくは「OK」を押すことで送信できます。  
フィードバックとして、正解なら「CA」,そうでないなら「WA」と表示されます。また、正答が表示されます。
## 問題のかきかた
行頭に「#」がある行はコメントとして受理されます。  
ある一つの問題について、「単語」「タブ」「意味」の順に記述します。例えば、以下のようになります。  
```
# この行はコメントとして受理されます
apple	        りんご
take care of	世話をする
in order to	    〜するために
as to	        〜するために
# 次のような行は無効です
ignore
無視をする
# フォーマットに則っていればどんな入力も受け付けます。
めでたし        素晴らしい
めでたし        立派だ
```
間の文字列がタブであることに注意してください。また、タブはいくつあっても構いません。  
行頭、行末のホワイトスペースは無視されます。
